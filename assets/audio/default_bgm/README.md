# 默认主 BGM 素材位

本目录预留给用户合法取得的音频，目前未附带实际音频。

- 曲目：秋成《若如初见》（We Never Remix）。
- 社区别名：开智小曲。
- 优先：0.9× Slow / Slowed 版本；已经放慢的文件不要再减速。
- 不从不明来源下载，不使用 AI 生成音乐或相似曲目替代；缺文件则等待用户提供。

用户提供文件后保留原件，记录实际文件名、版本、哈希与使用授权，按根目录 [VIDEO_STYLE.md](../../../VIDEO_STYLE.md) 分析 BPM、拍点与取用区间。不要仅凭文件名或旧模板的 77 BPM 判定已完成分析。

目录占位说明会进入 GitHub，音乐原文件默认忽略。请分别在本地和 Cloud 放置有权使用的同一素材；没有明确再分发授权时不要将音乐原文件提交到公开仓库。项目裁剪与混音输出放入各自工作目录，不覆盖这里的原件。
